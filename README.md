# CODE3D-AI

Full-stack project skeleton for CODE3D-AI educational platform.

## Directory structure
```
CODE3D-AI/
├─ frontend/      # React + Vite client
├─ server/        # Node.js + Express backend
├─ prisma/        # Prisma schema & migrations
└─ README.md
```

Run `npm install` in each sub‑folder then `npm run dev`.
